## 🌟 Featured Engineering Projects

<br/>

### 1. 🔍 [HalluciScope](https://github.com/Tarunjit45/HalluciScope)
> **Privacy-First Local LLM Autopsy & Hallucination Scoring System**

* **Problem Solved:** Generative AI models frequently output plausible hallucinated facts without verifiable citations, making them risky for local/private deployments.
* **Core Tech:** Python, Ollama, Local LLMs, Vector Analytics, NLP
* **Key Features:**
  * Runs 100% locally on low-spec hardware without cloud API dependencies.
  * Real-time semantic checking & confidence scoring for LLM responses.
  * Extensible diagnostic dashboard for model introspection.
* **Status:** Active Development | Open Source MIT

<br/>

### 2. 🛡️ [SpecGuard](https://github.com/Tarunjit45/SpecGuard)
> **Executable Unit Testing Framework for AI Safety & Behavioral Policies**

* **Problem Solved:** Prompts and system instructions often fail unpredictably. SpecGuard turns behavioral guidelines into automated, unit-testable assertions.
* **Core Tech:** Python, Automated Test Suites, CLI, Behavioral Rule Parsers
* **Key Features:**
  * Declarative policy assertion engine for LLM outputs.
  * Continuous integration hooks to catch AI regression bugs pre-deployment.
  * Rich assertion failure diagnostics and structured JSON reporting.
* **Status:** Production-Ready CLI | Contributions Welcome

<br/>

### 3. 🤖 [deepagents](https://github.com/Tarunjit45/deepagents)
> **Batteries-Included Autonomous Agent Harness & Task Execution Engine**

* **Problem Solved:** Building reliable autonomous multi-agent workflows requires low-overhead state management, tool execution, and self-healing error recovery.
* **Core Tech:** Python, Autonomous Agent Loops, Event Bus, System Metrics
* **Key Features:**
  * Lightweight subagent spawning and task distribution engine.
  * Standardized tool interfaces for file manipulation, API querying, and shell execution.
  * Built-in execution logging, sandboxing, and graceful error handling.
* **Status:** Core Framework Maintained | Active R&D

<br/>

### 4. 🔑 [API-Sentinel](https://github.com/Tarunjit45/API-Sentinel---Multi-Provider-Key-Validator)
> **Multi-Provider API Key Verification & Rate-Limit Sentinel**

* **Problem Solved:** Managing multiple AI and Cloud provider keys across microservices leads to silent failures when quotas exhaust or credentials expire.
* **Core Tech:** TypeScript, Node.js, Async Validation, REST APIs
* **Key Features:**
  * Concurrent validation across OpenAI, Anthropic, Google Gemini, and custom endpoints.
  * Instant status checking, quota diagnostics, and automated alerts.
  * Zero credential exposure architecture.
* **Status:** Maintained Utility | Open for PRs
