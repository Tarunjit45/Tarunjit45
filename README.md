## ⚡ HOW GOOD AM I IN TECH? (THE TECHNICAL ARSENAL)

I don't build superficial API wrappers or throwaway toys. Every system in this portfolio reflects architectural intentionality, robust error boundaries, deterministic fallbacks, and deep technical curiosity:

### 🤖 1. Autonomous Agents & Multi-Agent Cognitive Architectures
* **Stateful Orchestration:** Architecting autonomous agent execution graphs with **LangGraph**, deterministic state transitions, self-correcting error loops, and dynamic task replanning.
* **Execution Sandboxing & Tool Use:** Designing tool-calling harnesses with persistent scratchpads, sandboxed Python code execution, and rigorous output schemas.
* **Agent Flight Recorders:** Building cryptographic decision lineage tracers (`ChainWatch`, `DecisionTrace`) that create immutable, tamper-evident hash chains of every prompt, tool call, and decision.

### 🛡️ 2. AI Safety, LLM Evaluation & Local SLMs
* **Asynchronous Local Oversight:** Implementing zero-cloud agent supervision (`local-ai-safety-auditor`) utilizing local Small Language Models (Qwen/Llama on Ollama) to monitor cloud LLMs without confidential data egress.
* **Continuous Integration for LLMs:** Creating CI/CD behavioral regression frameworks (`PromptGuard`, `SpecGuard`) that run automated unit tests and semantic assertions against model updates.
* **Context Degradation & Hallucination Diagnostics:** Stress-testing context windows under high needle-in-haystack pressure (`ContextOS`) and profiling token waste (`TokenLens`).

### 🔍 3. Vector Databases & RAG Infrastructure
* **Vector Engines From Scratch:** Engineered **VextaDB**, a lightweight embedded vector database in Python with cosine distance indexing, metadata filtering, and fast nearest-neighbor retrieval.
* **Enterprise RAG Pipelines:** Building grounded RAG systems (`pdf-knowledge--base-rag`, `Conflux AI`) featuring semantic document chunking, hybrid keyword+dense vector retrieval, reciprocal rank fusion, and anti-hallucination citation checks.

### 👁️ 4. Computer Vision & Multimodal Perception
* **Real-Time Keypoint Tracking:** MediaPipe and OpenCV gesture controllers (`HandWave`, `Helios`) tracking 21 3D hand landmarks for latency-sensitive system audio and cursor manipulation.
* **Automated OMR & Edge Vision:** Computer vision evaluation algorithms (`OMR-Genius`) performing perspective correction and contour analysis to grade bubble test sheets instantly, alongside edge threat detection (`Rakshak-AI`).

### 🔒 5. Cryptography, Peer-to-Peer & Zero-Trust Systems
* **Serverless P2P Protocols:** Built **Anywhere Drop**, a zero-dependency serverless P2P file sharing engine operating over WebSockets and WebRTC data channels.
* **End-to-End Encrypted Wire Networks:** Engineered **VoidChat**, a decentralized, serverless LAN messenger with custom symmetric encryption wire protocols and zero reliance on central servers.

### 🌐 6. Full-Stack Engineering & Cloud Platforms
* **Modern Web Stack:** TypeScript, Next.js (App Router), React, Tailwind CSS, Node.js, Express, FastAPI, Python.
* **Databases & Caching:** PostgreSQL, pgvector, Redis, MongoDB, Firebase, SQLite.
* **Cloud & DevOps:** Docker containerization, Google Cloud Platform (BigQuery, Cloud Functions, Lakehouse architectures), Vercel, GitHub Actions CI/CD.
